Co je potřeba udělat — Sprint 1 bugfixy (3 kusy)

  Bug 1 — Google přihlášení nefunguje

  Problém: Popup se otevře, vybereš účet, ale pak se zavře a nic se nestane.
  Příčina: Po úspěšném Google OAuth se pokusí zapsat profil do Firestore. Když to selže, chyba se tiše spolkne — nikde se nezobrazí.
  Oprava:
  - src/providers/FirebaseAuthProvider.jsx — přidat try/catch kolem setDoc() v loginWithGoogle(), nastavit setError() při selhání
  - src/components/ui/GoogleSignInButton.jsx — přidat console.error do catch bloku
  - src/pages/login/components/LoginForm.jsx — upravit handleGoogleError() aby nezamlčoval chyby
  - src/pages/register/components/RegistrationForm.jsx — stejná oprava jako LoginForm

  Bug 2a — Presety ukazují "backend offline"

  Problém: Po přihlášení presety říkají že backend neběží, i když běží.
  Příčina: src/services/presetsApi.js používá raw fetch() bez Authorization headeru. Backend dostane request bez tokenu → vrátí 401 → frontend si myslí že     
  backend neběží.
  Oprava:
  - src/services/presetsApi.js — v apiFetch() přidat volání window.__authGetToken() a nastavit Authorization: Bearer <token> header

  Bug 2b — Backend neumí ověřit tokeny

  Problém: I kdyby se token poslal, backend ho neumí ověřit.
  Příčina: V backend-local/.env chybí FIREBASE_PROJECT_ID.
  Oprava:
  - backend-local/.env — přidat řádek: FIREBASE_PROJECT_ID=model-pricer
  - Restartovat backend
